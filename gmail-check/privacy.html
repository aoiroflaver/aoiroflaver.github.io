プライバシーポリシー

取得する情報

Gmail の読み取り専用の許可（https://www.googleapis.com/auth/gmail.readonly）で、メールの差出人・件名・日時・本文の冒頭・ラベルを読み取ります。メールの送信・削除・変更はしません。

外部への送信

読み取った情報の一部を、外部の AI サービス（TypeSafe、Anthropic）で処理します。販売・広告には使いません。

許可の取り消し

https://myaccount.google.com/permissions からいつでも取り消せます。

Google API Services User Data Policy

Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。
